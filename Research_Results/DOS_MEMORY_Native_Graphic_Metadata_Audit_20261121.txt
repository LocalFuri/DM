SOURCE TRACE
MEMORY.C F0489_MEMORY_GetNativeBitmapOrGraphic(index):
1. If already cached, returns M085_USED_BLOCK_BITMAP(cache block).
2. Otherwise accesses G0636_ppuc_Graphics[index], allocates cache block, and sets
   M106_USED_BLOCK_BITMAP_WIDTH(block) = M105_GRAPHIC_PIXEL_WIDTH(graphic)
   M107_USED_BLOCK_BITMAP_HEIGHT(block) = M089_GRAPHIC_HEIGHT(graphic)
3. Expands graphic via F0466_EXPAND_GraphicToBitmap and returns bitmap pointer.
DEFS.H: M085_USED_BLOCK_BITMAP(block) = block + 16; width/height are at block+12/+14, which correspond to bitmapPointer-4/-2 (M100_PIXEL_WIDTH and M101_PIXEL_HEIGHT).
DUNVIEW.C F0675 then reads M100/M101 and applies M078_SCALED_DIMENSION to write the scaled destination bitmap header.
