DUNGEON MASTER PC DOS — GENERIC 6-BIT INDEXED RENDERER CONTINUATION
Date: 2026-11-21. Research only. Do not modify Unity or original DOS installation.

INPUTS
- GRAPHICS_DOS.ZIP: original 713-graphic DOS GRAPHICS.DAT.
- DOS_All_Ornament_Geometry_F0635_Corrected_20261121.csv: existing checked geometry CSV for 60 types x 15 views.
- DOS_Manacles332_Indexed_20261121.bin: original native 92x52 image, original 4-bit palette indices.
- DOS_F0129_Exact_6bit_Verification_Package_20261121.zip: original exact F2 verification and FIRES evidence.

IMPLEMENTED
- Generic, data-driven extraction of each required original native graphic through dmcsb.image_indexed(), preserving the 0..15 indices.
- Shared 6-bit DOS shrink: step=(native_dimension<<6)//destination_dimension;
  sample_coordinate=((step>>1)+output_coordinate*step)>>6.
- Original D2/D3 palette index lookup tables. No RGB interpolation.
- Horizontal mirroring for the side-view rows flagged by the geometry CSV.
- Separately generated full scaled index image and viewport-clipped visible index image.
- No fallback for missing graphics, geometry, incompatible dimensions or invalid indexes.
- Outputs raw pixel-index .bin, diagnostic palette-index PNG with transparency 10, and per-view JSON manifest.

VALIDATION LIMITS
- Pixel-exact match is established independently only for Manacles center F2.
- Other views are generated using the same source-based rules but not independently validated against DOS screenshots.
- This is a sprite-index and clipping prototype, not a full dungeon compositing or wall-occlusion implementation.
- The palette for output PNGs is diagnostic grayscale, NOT DOS RGB. Binary files contain exact mapped indices.
- Original color indices and background composition must be verified in real DOS for additional perspectives.
- Mirror/clipping order should be independently checked where a mirrored sprite intersects a clipping boundary.
- No Unity edits and no individual ornament-specific corrections.
