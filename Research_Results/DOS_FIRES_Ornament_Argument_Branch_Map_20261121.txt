CONFIRMED DISPATCH MECHANISM

The structure-preparation function associated with live address 114C:1408 reads a byte from helper 114C:04B9 (the helper's exact data semantics remain undetermined), stores it at local [BP-05], and writes its zero-extended value to output structure +02. It shifts the byte right by five to compute the group in the range 0..7, writes this group to output +00, then checks whether group <=6 and dispatches using a seven-entry near jump table at CS:182E.

WHAT PRODUCES OUTPUT FIELD +0A (RENDERER'S FIRST ARGUMENT)

Group 1 enters 1696 and makes a CALL to 114C:12C1 at 16BA after passing a masked flag (local [BP-05] & 0008h), followed by MOV ES:[BX+0A],AX at 16C3. If the masked flag is zero, 12C1's guard at 12C5/12C9 sends execution to XOR AX,AX and the stored field is zero. Other conditions inside 12C1 can also produce zero.

A separate group-conditional loop at 16CD uses the generic encoded-record resolver 114C:07A1; if the derived group is 3, the word at output +0A is set at 16F0 from the top nibble of the resolved record's byte +05. A later branch at 1815 conditionally ORs 8000h into the existing value of output +0A.

This demonstrates several non-Hook-specific ways in which renderer argument one can be zero or nonzero. However, it does NOT prove which group or branch is used to draw the Hook at Level 1 (1,3) facing North, nor whether the paused calls correspond to an actual visible Hook. A zero argument is explicitly an early exit at the renderer.

Verified caller context: 2A64:33ED allocates a 14-byte local structure; 2A64:3404 calls 114C:1408 to fill it; the local at caller BP-04 (offset +0A) is subsequently pushed as the first argument to renderer 2A64:10E6 by 2A64:3474/3478.
